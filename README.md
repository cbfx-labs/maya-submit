# CBFX Maya Submit — releases

Installer zips for **CBFX Maya Submit**, the Maya 2025+ submitter for the CBFX
Deadline Cloud farm (V-Ray). Windows and macOS. No source, no credentials.

**Download:** [CBFX_Maya_Submit.zip](https://github.com/cbfx-labs/maya-submit/releases/latest/download/CBFX_Maya_Submit.zip)
(always the newest version).

1. Install Deadline Cloud Monitor and sign in with your own CBFX farm login.
2. Unzip, then run `install.bat` (Windows) or `install.command` (macOS).
3. Restart Maya. Use **CBFX › Submit to Farm…**

Installed copies update themselves: a new version downloads quietly when Maya
opens and runs from the next launch. The `channel` pre-release holds the
update manifest; don't download from it.
